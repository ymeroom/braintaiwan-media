# FB 輪播草稿 — 比 OK 開合 25 下（2026.08.23）

## 貼文文案

八月八日，高齡健康產業博覽會在台北世貿一館開展。台中慈濟醫院神經內科醫師郭啟中在講堂上請台下五十歲以上的人伸出一隻手，比出 OK，食指跟拇指快速開合二十五下，再換手。

這幾天這段內容在社群上被轉了一輪，標題大多寫「揪出巴金森早期警訊」。但很少人問：為什麼是二十五下，而不是直接看手抖不抖。

答案在診斷準則裡。2015 年國際動作障礙學會的準則把巴金森病的門檻放在「動作遲緩」，而不是手抖——沒有動作遲緩不會是巴金森病，沒有手抖卻可以是。更關鍵的是，準則對動作遲緩的定義不只是慢，還要求「重複動作時，幅度或速度持續遞減」。

遞減需要跑一段才看得出來，前三、五下往往完全正常。這就是二十五下的用途。

2012 年《Brain》的研究顯示，遞減幾乎是巴金森病的簽名：同樣是動作變小，PSP 的人從第一下就小卻不遞減，巴金森病的人一開始接近正常、然後一路縮水。

而 2025 年《npj Parkinson's Disease》的影片研究更進一步——他們只分析臨床醫師在量表上打「零分」、肉眼判定完全正常的手指開合。結果在被視為前驅期的快速動眼期睡眠行為障礙受試者身上，「慢」跟「小」都還看不出來，遞減卻已經量得出來了。

手在一下一下地縮小，大腦卻沒有把這件事回報給主人。那二十五下真正在問的，與其說是手指靈不靈活，不如說是大腦有沒有誠實地告訴你，你剛才那個動作到底做了多大。

### 卡 2｜手抖不是門檻
- **標題**：門檻不是手抖
- 2015 MDS 診斷準則：動作遲緩是必要條件
- 靜止性顫抖與僵硬，二選一即可
- 沒有動作遲緩，不會是巴金森病
- 沒有手抖，仍然可以是

### 卡 3｜關鍵字是遞減
- **標題**：愈做愈小
- 動作遲緩 = 慢 + 重複時幅度或速度遞減
- 醫學上叫 decrement、序列效應
- 前三五下往往完全正常
- 所以要做滿二十五下

### 卡 4｜遞減的簽名
- **標題**：兩種病兩條線
- 《Brain》2012：儀器量手指開合
- 巴金森病：起步接近正常，一路縮水
- PSP：第一下就小，卻幾乎不遞減
- 同樣變小，故障的腦區不同

### 卡 5｜醫師打零分的手
- **標題**：肉眼看不到
- 2025《npj PD》：66 人影片，只取醫師打 0 分的片段
- 前驅期（睡覺說夢話、揮拳）看不出慢與小
- 遞減卻已經量得出來
- 分辨準確率：巴金森 81.5%、前驅期 79.8%
